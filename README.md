CVF Steroid Analysis – Statistical Code

This repository contains the R code used to process, analyze, and visualize steroid measurements from cervicovaginal fluid (CVF) samples. The code includes data cleaning, statistical modeling, and figure generation for the associated manuscript.

Repository structure

analysis/ – R Markdown files used for data cleaning, statistical analyses, and model fitting.

data/ – Input datasets used in the analyses - at the moment I don't seem able to share the raw data *HELP*

images/ – Original figures generated during the initial analysis.

images_reviewed/ – Updated and re-processed figures created in response to reviewer comments.
